Your records. Ready to play.

A player for the music you already own, right on Discogs release pages. Connect your own Navidrome server to get started. Sign in again after restarting Chrome.

Connect your library

Your password is sent to your chosen server and is not saved by this extension. Login tokens stay in memory for this Chrome session. To match releases, the extension sends the current Discogs release ID to the Discogs API and catalog queries to your server. No analytics. Privacy policy.

Playback & matching

Optional Discogs API token

Optional; kept in memory until Chrome restarts. Usually unnecessary for release lookups. If Discogs requires authentication, create a personal token in Discogs Settings → Developers.

Check your connection

Paste an album URL from your library or search an imported catalog number. These checks do not require a Discogs page.

After connecting, open any discogs.com/release/… page. Reload Discogs tabs that were open during installation. Master-release and marketplace pages are not supported in this first version.
